# ARMAGEAR — Company Website

Official marketing website for ARMA GEAR — FZCO, a Dubai-based technology company building tailor-made business management systems, AI-integrated operations, portals and educational platforms.

## Stack
Single-file static site (`index.html`) — HTML, CSS and vanilla JavaScript. All assets (logos, founder portraits, product icons) are embedded as base64, so there are no external image dependencies.

## Deploy
Static hosting. On Vercel, no build step is required — the root `index.html` is served directly.

- Hero — pixel-assembly emblem + code-rain background
- 01 Belief · 02 Systems · 03 Process · 04 Products · 05 Company (founders)
